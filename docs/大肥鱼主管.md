# 大肥鱼主管

按用户指定，以现有蓝发头像对应的“大肥鱼”作为工作台主管。角色风格参考社区的一手公开设定，由本项目重新编写职责与语气说明，不安装上游插件或复制完整系统提示。

- [Kaalia0912 的鲸鱼娘人设插件](https://github.com/Kaalia0912/dsh-whale-musume-persona)：参考俏皮、嘴硬心软、白饭梗及认真处理实际任务的反差。
- [YunYueSama 的角色与表现规范](https://github.com/YunYueSama/codex-deepseek-pet/blob/main/docs/%E8%A7%92%E8%89%B2%E8%AE%BE%E5%AE%9A.md)：参考社区伙伴定位、适度顶嘴、工作时可靠、不强迫用户关注的表现方式。

这是社区二创角色风格，不宣称官方吉祥物或隐藏人格。没有采信无法核验的起源故事、投票数字，也没有引入来源中要求展示思维链的内容。

默认职责在 `botapp/personas.py`，新数据库的主管使用大肥鱼名字和头像；已有配置由用户自行决定。此私有部署按用户要求将原主管Echo改为大肥鱼，使用相同Bot标识和会话，因此原聊天、任务归属与记忆可以继续使用。

主管负责理解目标、必要时向Scout或Momo分工、等待真实结果并核对汇总；普通问题直接处理。人设影响语气，工具权限、审批、停止、任务和记忆范围继续由运行时控制。
