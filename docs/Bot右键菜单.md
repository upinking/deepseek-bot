# Bot 右键菜单

在主管卡片或联系人上点击鼠标右键，可以操作这个 Bot，当前聊天保持原位。键盘可用菜单键或 Shift+F10；触屏支持长按约半秒，滑动时取消长按。

## 功能

- **置顶 / 取消置顶**：普通 Bot 放到置顶区域，主管保持在最上方；同一个联系人只显示一次。
- **移动到分组**：展开二级菜单，选择未分组或已有分组，也可以新建、管理分组。分组整理侧栏，群聊用于共同对话。
- **标为未读 / 已读**：保留手动未读圆点，下次主动打开该 Bot 时清除。
- **重命名 Bot**：只修改这个 Bot 的名字及对应单聊标题。
- **职责与头像**：进入既有的 Bot 编辑页。
- **设为主管**：更换主助手，沿用该 Bot 的身份、会话与记忆。
- **复制对话 ID**：复制对应单聊标识；浏览器不允许直接复制时，显示可选中的文本。
- **从侧边栏隐藏**：收起联系人入口，任务、聊天与记忆保留。从账户菜单或新建菜单的“隐藏的 Bot”中恢复。
- **删除 Bot**：先显示删除范围并要求输入名字；主管需先交接职责，有未结束或正在收尾的任务时暂缓删除。

这些整理状态保存在服务器，电脑和手机读取同一份配置。删除分组会把其中的 Bot 放回未分组，保留他们的记录。

## 菜单交互

白色圆角菜单使用图标、分隔线和红色删除项，参考用户提供的 Grok 截图。菜单与目标 Bot ID 绑定，联系人轮询重绘后仍作用于原对象。

方向键与 Home/End 选择项目；→ 键展开分组子菜单，← 键返回，Escape 逐层关闭，Tab 或点击外部收起。菜单会避开屏幕边界，空间不足时将分组改为带返回键的同位置子面板。长按期间和松手后的短暂点击会被抑制，避免打开菜单时误进入聊天。

## 私有接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/sidebar` | 返回 `bots` 偏好映射与 `groups` 分组列表。 |
| `PATCH /api/bots/{id}/sidebar` | 局部修改 `pinned`、`hidden`、`unread`、`group_id`。 |
| `POST /api/bot-groups` | 创建分组，名称 1～40 字，最多 30 个。 |
| `PATCH /api/bot-groups/{id}` | 重命名分组。 |
| `DELETE /api/bot-groups/{id}` | 删除分组，将成员恢复到未分组。 |

接口复用登录、同源写请求和禁止缓存机制。偏好更新在同一 SQLite 事务中读取并合并，避免不同设备修改不同字段时相互覆盖。
