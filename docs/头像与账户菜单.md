# 头像与账户菜单

形象参考[社区鲸鱼娘角色设定](https://github.com/YunYueSama/codex-deepseek-pet/blob/main/docs/%E8%A7%92%E8%89%B2%E8%AE%BE%E5%AE%9A.md)与用户提供的蓝发图像。采用内置 `image_gen`，以原图为身份和画风参考，新生成主管肖像；没有直接下载社区插画作为成品。

## 账户菜单

左下角固定显示圆形用户头像、名字和“私人工作台”。点击后向上弹出菜单，布局参考用户提供的 ChatGPT 截图。没有头像时显示名字首字；通用初始名字为“我”。

- **个人资料**：改名字、上传或移除头像，点击保存后跨设备同步。上传支持 PNG、JPG、WebP，原图最多 10 MB；前端缩至最长边 256 像素后提交。
- **个性化**：进入主管职责与说话风格编辑，或管理偏好记忆、技能。
- **设置**：复用现有模型连接、通知及登录密码设置。
- **记忆、技能、例行、文件**：原工具入口全部保留，集中在菜单内。
- **帮助、退出登录**：提供真实使用说明；退出会删除当前会话 Cookie 对应的服务器登录记录。

菜单支持方向键、Home、End、Escape；Tab、外部点击及关闭移动侧栏也会收起菜单。名字与头像只通过已登录的私有接口读取，不写进应用外壳缓存或公共默认配置。

## 个人资料接口

两个接口均需工作台登录态，并使用既有的同源 Cookie 与写请求校验。路径随工作台的部署前缀变化。

| 接口 | 行为 |
| --- | --- |
| `GET /api/profile` | 返回 `{ "display_name": "我", "avatar_data": "" }` 形状的当前资料。 |
| `PUT /api/profile` | 接受 `display_name`、`avatar_data` 两个可选字段，保留未提交的字段，返回保存后的完整资料；未知字段会被拒绝。 |

`display_name` 去掉首尾空白后需为 1～64 字符。`avatar_data` 为空字符串时清除头像，否则需为 PNG、JPEG 或 WebP 的 Base64 data URI，解码后不超过 256 KB；服务端检查编码和图片格式结构，不接受 SVG、远程 URL 或其他 MIME。

资料保存在现有数据库的私有 `user_profile` 设置中，与模型密钥分开。该功能仍属于单用户工作台，不创建公开个人主页或额外账号。
