# 第一版开发接口约定

2026-10-31。使用 Python ≥3.10、FastAPI、SQLite、httpx、Playwright；静态原生 HTML/CSS/JS PWA。数据库 UTC Unix 秒，界面 Asia/Shanghai。所有 API 返回 JSON；列表直接数组；创建资源返回对象；错误 `{detail: 中文信息}`。单用户登录 Cookie，所有 `/api/*`（auth/status、auth/login 除外）由 main.py 统一认证与同源检查。

## 模块与持久数据

`botapp/store.py`: Store(data_dir)，属性 data_dir(Path)、db_path；方法 all(sql, params=()), one(sql, params=()), execute(sql, params=())（返回 lastrowid），transaction()（context manager 返回 sqlite connection）；get_setting(key, default=None)、set_setting(key,value)；event(task_id,kind,detail)；add_message(conversation_id,bot_id,role,content,task_id=None,metadata=None)；create_task(conversation_id,bot_id,prompt,kind='chat',parent_id=None,source=None)。JSON字段在数据库保存JSON文本，API输出解码。

表（agent1负责建表及默认数据）：
- bots(id TEXT PK,name,role,avatar,color,is_primary INT,created_at REAL)
- conversations(id PK,title,kind='direct'|'group',members JSON,created_at,updated_at)
- messages(id PK,conversation_id,bot_id nullable,role='user'|'assistant'|'system',content,task_id nullable,metadata JSON,created_at)
- memories(id PK,bot_id nullable（NULL共享）,content,created_at,updated_at)
- tasks(id PK,conversation_id,bot_id,prompt,kind,status='queued'|'running'|'waiting_config'|'waiting_user'|'waiting_approval'|'paused'|'succeeded'|'failed'|'cancelled',parent_id nullable,source JSON,context JSON,error nullable,result nullable,stop_requested INT,takeover INT,created_at,updated_at)
- events(id INTEGER PK AUTOINCREMENT,task_id,kind,detail JSON,created_at)
- skills(id PK,name,content,bot_id nullable,created_at,updated_at)
- routines(id PK,bot_id,conversation_id,name,prompt,kind='reminder'|'agent'|'checkin',schedule='once'|'daily'|'interval',run_at REAL nullable,time_of_day nullable,interval_seconds nullable,timezone='Asia/Shanghai',enabled INT,next_run_at REAL,last_run_at nullable,skill_id nullable,last_result nullable,created_at)
- routine_runs(id PK,routine_id,task_id nullable,status,scheduled_at,created_at,finished_at nullable,error nullable)
- files(id PK,name,path,mime,size,task_id nullable,created_at)
- settings(key PK,value JSON)
- sessions(token_hash PK,expires_at REAL)

Store初始化设WAL、busy_timeout，迁移兼容幂等。重启把running变paused并记event，不自动重放可能已提交外部动作。空数据库默认三个角色大肥鱼（主管）、Scout（研究）、Momo（生活）；每人一个direct对话。已有Bot的名字、职责和头像不会在重启时被默认值覆盖。

## HTTP契约

Root main.py: GET /api/auth/status -> {authenticated,setup_required}; POST /api/auth/setup {password}; POST /api/auth/login {password}; POST /api/auth/logout。首次部署密码通过本地环境生成，不开放公网抢注。GET /api/settings -> {model,api_base,has_api_key,browser_available,timezone,...}; PUT /api/settings {api_key?,model?,api_base?,...}; POST /api/settings/test -> {ok,detail}（实际模型调用）。

Agent1 domain.py: `install_routes(app,store,runtime)` 注册以下API：
- GET/POST /api/bots；PATCH/DELETE /api/bots/{id}；POST /api/bots/{id}/primary
- GET/POST /api/conversations（POST {title,kind,members}）；GET /api/conversations/{id}/messages；POST /api/conversations/{id}/messages {content,bot_id?,file_ids?} -> {message,task}，立即返回，由worker后台执行；DELETE /api/conversations/{id}/messages（只清空聊天）
- GET /api/tasks（?conversation_id）；GET /api/tasks/{id}；GET /api/tasks/{id}/events（?after=integer）；POST /api/tasks/{id}/stop；POST /api/tasks/{id}/resume {message?}；POST /api/tasks/{id}/approval {allow:bool}；POST /api/tasks/{id}/takeover {enabled:bool}
- GET/POST /api/memories（?bot_id=...，包含共享）；PATCH/DELETE /api/memories/{id}
- GET/POST /api/skills；PATCH/DELETE /api/skills/{id}
- GET/POST /api/routines；PATCH/DELETE /api/routines/{id}；POST /api/routines/{id}/run；GET /api/routines/{id}/runs

Agent1 scheduler.py: Scheduler(store)，async start/close；轮询到期计划，原子领取并保存run。reminder直接持久消息无需模型；agent/checkin创建task。持久化、关浏览器仍跑、失败留记录、防同一轮重复。每日时区、interval≥60秒；一次任务不删除，只禁用；checkin静默时段/频率。

Root browser.py: BrowserController(data_dir, cdp_url optional)。async start/close/status/task_snapshot(task_id)/action(task_id,action,args,manual=False)/screenshot(task_id)。按任务独立页面、共享profile，lock串行操作。action支持 open{url},snapshot{},click{ref},fill{ref,text},scroll{dy},back{},tabs{},new_tab{url},switch_tab{tab_id},download{ref},upload{ref,file_id},keypress{key}。返回dict含title,url,text,elements[{ref,role,name,type}],image_url?，snapshot元素包含sensitive(bool)；ref是上次snapshot分配的引用。只允许HTTP(S)公开地址；下载/上传限工作区。screenshot返回bytes。takeover用户点击可额外支持coordinate_click{x,y}。不开放任意shell或JS。

Root browser/file routes: GET /api/browser/{task_id}/snapshot；GET /api/browser/{task_id}/screenshot（PNG）；POST /api/browser/{task_id}/action {action,args}，仅task.takeover=1允许人工动作；POST /api/files（multipart file）-> file object；GET /api/files；GET /api/files/{id}/download。任务页预览用于用户接管输入，密码字段内容不得记录events。

Agent2 runtime.py: Runtime(store,browser)，async start/close/notify/stop_task/resume_task/approve_task/set_takeover。使用httpx调用真实DeepSeek API（默认deepseek-flash，thinking disabled），key缺失waiting_config，绝不假回答。工具循环记录工具活动与结果、保存context，多角色/群聊、记忆增改删、技能、提醒与例行任务、受控浏览器、Bot交接、工作区文件写入。模型不得执行shell。循环最多24步，handoff最多2跳。执行中stop与接管优先检查；网络异常失败显示原因；API密钥不出现在日志或前端。runtime model请求可被测试注入替代，但生产无假模型开关。

前端Agent3: 仅维护 web/，严格用这些HTTP接口；登录、联系人、群聊、聊天/任务时间线、浏览器预览/接管、设置APIkey、记忆/技能/例行任务管理、文件、PWA安装/重连。轮询后端保存状态（2s活跃、慢速空闲）；所有功能真实按钮可用，服务端不可用时明确错误。浏览器操作视图支持截图坐标点击、DOM ref选择/输入/按键、地址栏。密钥只写一次，不读取回显；textContent防XSS。手机<=400px可用。样式参考用户截图：简洁联系人+圆润对话，采用自有SVG头像，不复制品牌素材。
