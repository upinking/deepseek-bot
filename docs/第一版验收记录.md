## 真实 DeepSeek 联调

用户自行在设置页保存密钥后，以两个临时 Bot 和一个临时群聊进行验收。模型为 `deepseek-flash`，通过生产运行时调用官方 API；未读取或输出用户密钥。

| 范围 | 实际证据与结论 |
|---|---|
| 连接与中文聊天 | 设置页连接测试收到真实“连接成功”；普通任务返回中文学习建议及 `17×23=391`。事件有模型请求、实际用量和完成记录。 |
| 模型自主浏览与成果 | Bot 实际打开 `https://example.com/`，点击 Learn more 跳转 `https://www.iana.org/help/example-domains`；工具返回对应的 URL、标题与正文。随后 `file_write` 生成906字节 Markdown，认证下载200，内容包含两页实际来源。证据：`output/qa/browser_file.json`、`downloaded-browser-report.md`。 |
| 离开提交客户端后继续 | 提交浏览任务的客户端立即退出，没有保持长连接；任务继续访问、点击、生成文件，后续新客户端能读取完整结果。此项没有把关闭客户端当作停止操作。 |
| 私有记忆与隔离 | A 真实调用 `memory_save` 保存虚构代号；从 B 的实际网页聊天框发送请求，B 调用 `memory_list` 后回答没有该代号，B 的有效记忆没有 A 的私有记录。 |
| 纠正与遗忘 | 更新同一记忆 ID 后只有新值；`memory_delete` 删除后记录为空，再次询问时模型明确没有记录，未恢复旧代号。修订事件清除旧模型上下文。证据：`memory_correct.json`、`memory_forget.json`、`memory_verify_forget.json`。 |
| 群聊真实交接 | 修复子任务上下文后，A 实际 `handoff` 给 B；独立子任务有正确 `parent_id`，B 返回 `391×17=6647`，没有再次交给自己；父任务收到 `handoff_result` 后核对并汇总。证据：`handoff_fixed.json`、`handoff-fixed-children.json`。 |
| 停止与追加要求 | 在实际模型请求执行中停止，任务变为 cancelled，此后没有工具动作或最终回答。另一个多页任务完成首个浏览步骤后追加新目标，返回原任务 ID，有 `steered` 事件，最终只回答新目标标记，没有继续旧工具步骤。证据：`stop.json`、`steer.json`。 |
| 技能与提醒 | 模型真实保存私有技能，再 `skill_read` 按步骤核对 `28×15=420`；模型创建北京时间16:41:54的一次提醒，后台到期实际投递，运行历史及提醒消息均只有一条。证据：`skill_routine.json`、`skill_read.json`、`real-reminder-result.json`。 |
| 网页下载与预览 | 修复后，生成文件自动附在最终消息下；实际 Chrome 点击附件成功下载108字节中文文本，链接包含正确 `/deepseek/` 前缀。任务状态同步为“已完成”，云浏览器显示 IANA 实际页面及截图。证据：`output/playwright/live-final.png`、`live-ui-report-downloaded.txt`。 |

联调中修复了生成文件缺少消息附件、任务状态显示滞后，以及子 Bot 误读原始群指令的问题。所有 handoff 子任务现在只接收完整明确的分派说明，不自动继承委派者的聊天历史；必要事实、来源和约束由委派者写入说明。模型仍可能使用较繁复的确认文字，不能把自然语言自述当作工具成功证据。

云浏览器预览曾因后台标签未绘制而间歇超时。已改为截图前激活目标标签，并让前端等待每张图片载入完成再刷新，失败时保留上次成功画面；隔离 Chrome 验证慢图、坏图和切换任务不会叠加请求或显示过期结果。上线后连续三次截图均200，耗时约0.58、0.15、0.14秒，证据见 `output/qa/screenshot-fix-result.json`。验收结束清理临时 Bot、群聊、计划、技能和生成文件，证据仅保存在本地忽略目录。

在真实安卓设备检查安装、前后台切换和锁屏推送。手机尺寸模拟不等同于真实手机验收；推送服务接受也不等于通知实际显示。该项没有标记为已通过。

## 交付边界

当前为个人单用户网页/PWA，不包含原生 APK、语音通话、本机电脑控制或任意终端执行。浏览器使用页面结构与文本驱动，截图用于用户预览与接管；复杂视觉页面可能需要人工帮助。网站自身的登录过期、验证码和反自动化限制仍可能中断任务。

服务器源码和浏览器进程已独立于原有浏览器服务；原有域名的临时应用路由已移除，正式入口按用户要求使用 IP。密钥与登录信息不提交到源码仓库。
